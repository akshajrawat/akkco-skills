# Akkco Bruteforce

## Execution Modes

### Standard (default):

`akkco-plan` → `akkco-implement` → `akkco-review`

### RSI:

`akkco-plan` → `akkco-rsi`

Use RSI when explicitly requested or when complexity and risk justify repeated reviews and corrections.

Announce the selected mode before execution.

Follow each skill's instructions, preserve the original user requirements, and pass relevant outputs between stages.

Do not duplicate nested skill executions or silently skip stages.
Report material blockers.

## Completion

Consolidate the results into a concise report covering:

- Implementation summary.
- Important decisions and deviations.
- Review findings and resolutions.
- Short architectural mind map.
- Key files and functions in execution-flow order for human review.
- Verification evidence and limitations.
